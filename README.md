# Cortado Sans
A clean geometric font with playful, extended strokes and asymmetrical curves. It’s the perfect everyday sans-serif with a shot of personality.

 Be easy on me this is my first font without any really investigation or research besides a few Glyphs Tutorial on Youtube. But hopefully it's still nice enough to be considerated for your next project.
